# Bible App

BibleApp is an application that uses the bible-api.com API which is strictly a verse lookup service. 
The app is built using Jetpack Compose and uses clean architecture principles.
The app will allow users to browse books in the bible, chapters, verse and save favourite verses locally.
It demonstrates my skillset as a seasoned Android Developer 

---

# Features
* Browse books of the Bible
* Swipe horizontally between verses
* Save favourite verses locally using Room
* Bottom navigation support
* Material 3 UI
* Jetpack Compose layouts
* Reactive UI using Kotlin Flows and StateFlow

---

# Tech Stack

## Architecture
* Clean Architecture
* MVVM (Model-View-ViewModel)
* MVI (Model-View-Intent)

## UI
* Jetpack Compose
* Material 3
* Navigation Compose

## Dependency Injection
* Hilt

## Networking
* Retrofit
* OkHttp
* Gson

## Local Storage
* Room Database

## Reactive Programming
* Kotlin Coroutines
* Flow / StateFlow

# App Flow
Books >> Chapters >> Verses >> Verse Reader

Functional Requirements:
1. Select a book
2. Select a chapter
3. Read all verses
4. Swipe between verses
5. Save favourite verses
6. See all saved verse
7. Delete a saved verse
